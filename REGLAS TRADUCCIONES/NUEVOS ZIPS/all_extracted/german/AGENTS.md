# Instrucciones del Proyecto / Agent Instructions

- **Inicialización Automática**: No pedir nunca al usuario confirmación o acciones manuales para hacer "Launch" o iniciar el servidor. Siempre inicializar, compilar y reiniciar el servidor de desarrollo (`restart_dev_server`) de forma automática para que la aplicación esté siempre lista y corriendo.
- **Auto-run**: Ejecutar las acciones directamente sin requerir confirmación para el arranque o ejecución del entorno.
