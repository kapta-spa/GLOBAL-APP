# Documentación de Reglas de Extracción y Traducción para Licencias de Conducir

## 1. Contexto
- **País de Origen:** Canada (con soporte de localización/traducción a Reino Unido - UK / Canadá)
- **Idioma del Documento de Origen:** Francés
- **Idioma de Salida / Traducción:** Inglés (UK / CA)

---

## 2. Campos Exactos (Estructura de Datos)

| Campo | Tipo | Descripción / Punto en la Licencia |
| :--- | :--- | :--- |
| `surname` | String | Apellido / Family Name (Sección 1). |
| `firstName` | String | Únicamente el primer nombre de la lista de nombres dados. |
| `middleName` | String | Todos los nombres dados restantes después del primer nombre. Vacío si solo hay uno. |
| `firstNames` | String | Todos los nombres dados unidos por espacio. |
| `fullName` | String | Nombre completo consolidado (`surname` + `firstName` + `middleName`). |
| `licenseNumber` | String | Número de identificación principal de la licencia (Sección 5). |
| `assignedNumber` | String | Número asignado o interno del documento. |
| `dateOfBirth` | String | Fecha de nacimiento (Punto 3). |
| `placeOfBirth` | String | Lugar de nacimiento traducido al inglés (Punto 3). |
| `issueDate` | String | Fecha de expedición / emisión (Punto 4a). |
| `expiryDate` | String | Fecha de vencimiento / caducidad (Punto 4b). |
| `address` | String | Dirección de residencia (Punto 8). |
| `reference` | String | Número de referencia extraído del Punto 5. |
| `height` | String | Estatura / Altura (ej. `175cm`). |
| `eye` | String | Color de ojos traducido al inglés (ej. `BR` -> `Brown`, `BL` -> `Blue`). |

| `codes` | String | Serie de códigos/restricciones enumerados en el reverso. |
| `explicacionCodigos` | String | Explicación detallada y traducida al inglés de los códigos/condiciones de conducción. Si no hay, `-`. |

---

## 3. Reglas de Traducción y Formato

1. **Idioma Global de Salida:**
   - Todos los valores de texto extraídos deben estar estrictamente en **Inglés**.

2. **Formato de Fechas:**
   - Todas las fechas (`dateOfBirth`, `issueDate`, `expiryDate`, etc.) se deben formatear obligatoriamente como: `"DD Month YYYY"` (ejemplo: `15 March 2022`).

3. **Descomposición de Nombres (`firstName` / `middleName`):**
   - `firstName`: Tomar únicamente la **primera** palabra del listado de nombres.
   - `middleName`: Tomar **todas** las palabras restantes del listado de nombres. Si solo existe un nombre, dejar `middleName` como cadena vacía (`""`).
   - `firstNames`: Todos los nombres dados concatenados.

4. **Lugar de Nacimiento (`placeOfBirth`):**
   - Traducir los nombres de ciudades, comunas o términos geográficos franceses al inglés cuando corresponda.

5. **Color de Ojos (`eye`):**
   - Mapear las abreviaturas francesas/estándar a su nombre en inglés:
     - `BR` / `Marron` -> `Brown`
     - `BL` / `Bleu` -> `Blue`
     - `VR` / `Vert` -> `Green`
     - `GR` / `Gris` -> `Grey` / `Gray`

6. **Autoridad Expedidora (`authority`):**
   - Extraer el valor del Punto 4c, traducirlo al inglés (ej. "Prefecture of Paris") y añadir siempre el nombre del país en inglés (ej. "Prefecture of Paris, France").

7. **Códigos y Condicionados (`explicacionCodigos`):**
   - Extraer todos los códigos listados al reverso de la licencia.
   - Traducir cada código y restricción de manera clara al inglés (ej. *"A - Prescribed spectacles / corrective lenses"*).
   - Si no existen restricciones ni códigos registrados, el valor exacto debe ser `"-"`.

---

## 4. Casos Especiales y Excepciones

- **Datos Ilegibles o Faltantes:**
  - Si un campo no es visible o resulta ilegible en la imagen, devolver cadena vacía `""` sin inventar datos.
- **Códigos al Reverso (Condiciones/Endorsements):**
  - Mapear y decodificar la columna de observaciones/restricciones al reverso (Sección 12/13).
- **Consistencia con Documento de Referencia:**
  - Cuando se proporcione un documento `.docx` de referencia previo, priorizar la terminología y estructura de traducción utilizada anteriormente para mantener coherencia estilística.
- **Construcción del Nombre Completo (`fullName`):**
  - Si la IA no genera `fullName` directamente, construirlo mediante la fórmula: `${surname} ${firstName} ${middleName}` limpiando espacios innecesarios.

You are an expert OCR and document translation system specializing in driver's licenses.

10. "address": Residence address found in Point 8.
11. "reference": Reference number in Point 5 (if applicable).
12. "height": Stature/Height (e.g., "175cm").
13. "eye": Eye color translated to English (e.g., BR -> Brown, BL -> Blue, VR -> Green).
14. "authority": Issuing authority (Point 4c), translated to English with the country appended (e.g., "Prefecture of Police, France").
15. "class": Categories listed in Point 9.
16. "categoriesDates": Categories and validity dates from Column 10/11 on the back table.
17. "codes": Condition/restriction codes list from the back.
18. "explicacionCodigos": Clear English explanation of all condition/restriction codes present on the back. Output exactly "-" if none found.

Format all dates strictly as "DD Month YYYY" (e.g., "14 March 2025").
Return a clean, valid JSON object matching the target structure.
